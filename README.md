# Protocol Explorer — Independent Learning Edition

Responsive browser-based networking education lab. Independent implementation; no proprietary source or assets copied.

## Features
- 39 protocol lessons across Core, Application and Security.
- Animated simulated message flows and sequence view.
- Step, previous, next, restart and playback speed controls.
- Packet inspector with illustrative hexadecimal bytes and explanations.
- 204-question practice bank; 20 randomized questions per attempt, feedback and scoring.
- Browser-local progress, dark/light theme, protocol search and mobile layout.

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Vercel
Static site. Framework preset: Other. Build command: none. Output directory: `.`.

## Accuracy and safety
All traces are predefined educational simulations. They do not sniff packets, scan networks, connect to example endpoints, or represent live network evidence. Hex values are illustrative teaching bytes, not complete standards-conformant captures. Consult the relevant RFCs for implementation details.
